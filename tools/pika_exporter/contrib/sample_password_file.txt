# Pika Password File
# One password per line, lines starting with '#' are comments
# Empty lines are ignored
#
# When used with -pika.password-key, each line should be an AES-GCM encrypted password
# Use pika_encrypt_tool to generate encrypted passwords:
#   pika_encrypt_tool -password <plaintext> -key <encryption_key>
#
# Example (plaintext):
# 7bb34209
#
# Example (encrypted):
# <base64-encoded-encrypted-password>
